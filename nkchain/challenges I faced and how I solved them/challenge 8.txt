The reason why I got this error was because in the "db.flush" line of the "def fund_wallet" function of the "app\services\ledger_service.py" file, it was supposed to be "db.flush()" and not simply "db.flush".

Because db.flush was missing parenthesis, python treated it as a reference to the method itself instead of calling and executing it. This resulted in PostgreSQL never assigning an "id" to "transaction". this left "transaction.id" as None when "funding_entry" was created.
